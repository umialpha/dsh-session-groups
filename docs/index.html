DSH Session Groups

独立安装的 DSH Web 插件：在原生工作区项目树上方提供跨项目的置顶 Session 分组，同时保留官方 Workspace 行为。

当前状态

T-002 已完成可安装置顶分组、持久化和拖放实现，自动测试与安装验证已通过，真实鼠标拖放仍待验收。历史设计与评审材料可从 Git 历史查阅。

作者为 umialpha <roy236977634@gmail.com>。T-003 已公开预览源码与安装说明；T-004 已发布 官方社区预览帖，1024 目录投稿已审核并合并。npm 尚未发布，真实鼠标拖放仍待验收。

约束

  • 不修改用户安装的 DSH 源码。
  • 一个 bundle 完成官方 Workspace 替换和分组功能装配。
  • 支持版本精确绑定，避免 DSH pre-stable Client API 漂移导致静默损坏。

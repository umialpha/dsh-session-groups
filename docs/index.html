DSH Session Groups

独立安装的 DSH Web 插件：在原生工作区项目树上方提供跨项目的置顶 Session 分组，同时保留官方 Workspace 行为。

当前状态

作者为 umialpha <roy236977634@gmail.com>。T-003 已公开预览源码与安装说明；T-004 已发布 官方社区预览帖，1024 目录投稿已审核并合并。T-005 的四个 0.1.0 包已发布到公共 npm；公开安装、启动、移除和官方 Workspace 恢复验证通过，真实鼠标拖放仍待验收。

用户安装入口：@umialpha/dsh-session-groups。仅支持 DSH 0.2.1-alpha.2；完整命令见仓库 README。T-006 已提交目录说明更新 PR #593，静态审核通过，等待维护者合并；目录网站的安装入口同步尚未核实。

约束

  • 不修改用户安装的 DSH 源码。
  • 一个 bundle 完成官方 Workspace 替换和分组功能装配。
  • 支持版本精确绑定，避免 DSH pre-stable Client API 漂移导致静默损坏。

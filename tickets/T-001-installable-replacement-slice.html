目标

上下文

这是 D-001 的 First Slice Check。它优先验证独立包构建、客户端动态入口、Typert Remote、自带 patch、精确版本 gate 和恢复路径，不在这一阶段完成全部拖放与 CRUD。

验收标准

  • 独立仓库可安装依赖并构建四个可发布包，产物不依赖 DSH checkout 内部路径。
  • Registry Client entry 自行通过 ctx.remote.$mount() 挂载生成 contribution，不修改官方 api-remotes。
  • bundle 精确绑定 DSH 0.2.1-alpha.2，停用官方 ui-workspace 并激活替代入口。
  • 在干净 profile 中可看到项目树前的置顶区域，官方当前目录发现和项目树仍可用。
  • 停用 bundle 并重启后，官方 Workspace 恢复。
  • First Slice architecture review 无阻断项。

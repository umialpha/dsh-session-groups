T-002 完整置顶分组与拖放体验

状态：doing / 优先级：P1 / 类型：feature / 分级：L — 完成持久化 CRUD、跨模块拖放、原生 Session 操作适配与发布交付。

目标

在已通过 R-002 的独立安装链路上实现完整置顶区域：默认层、自定义分组、折叠与排序、跨项目 Session 拖放、自动置顶、重启持久化和原生 Session 操作。

验收标准

  • 项目树上方直接显示置顶默认层和命名分组，不使用 tab，不显示“未分组”标签。
  • 可创建、重命名、删除、折叠和排序分组；可在默认层、组内和组间拖动 Session。
  • 可从任意项目拖入未置顶 Session，接受后自动置顶并保存目标位置。
  • blank Session 仅可打开，无菜单、时间和拖动；普通 Session 保持设计文档规定的原生操作语义。
  • 刷新和重启后布局保留；打包安装、禁用恢复和浏览器视觉/交互验收通过。
  • 根 README、LICENSE、THIRD_PARTY_NOTICES 与安装说明完整。
